# 最終レビューチェックリスト

## 検証ブリーフ

- [ ] 対象ユーザーが1つ以上明記されている
- [ ] 解決する課題が明記されている
- [ ] 期待するユーザー成果が明記されている
- [ ] 検証する仮説と最大リスクが明記されている
- [ ] 観測した要件、利用者の回答、推論した仮定が混同されていない
- [ ] 不明だった項目を推論した場合、前提と確信度が記録されている
- [ ] ビジネス成果が機能の完成ではなく、期待する行動変化として定義されている
- [ ] 今回のワイヤーフレームで得たい最重要学習が1件に絞られている

## スコープ

- [ ] 主要タスクが1つに絞られている
- [ ] 各画面が主要タスクまたは必要な状態を支えている
- [ ] 検証に不要な画面や装飾を含めていない
- [ ] 未対応範囲を未解決事項として記録している

## フロー

- [ ] 開始画面が一意である
- [ ] 主要フローが完了または中断状態に到達する
- [ ] すべての操作先が存在する
- [ ] エラーを含めた場合、回復経路がある
- [ ] 操作ラベルから結果を予測できる

## 表現

- [ ] 低忠実度であることが視覚的に明確である
- [ ] Lorem ipsumを使っていない
- [ ] 色だけで状態を表していない
- [ ] 320px前後で主要情報が欠けない
- [ ] 1280px前後で読みにくい過度な横幅にならない

## アクセシビリティ

- [ ] HTMLの言語が設定されている
- [ ] 見出し階層が破綻していない
- [ ] 操作にbuttonまたはlinkを使っている
- [ ] 入力に可視ラベルがある
- [ ] キーボードフォーカスが見える
- [ ] タップ領域が極端に小さくない

## 証拠

- [ ] 構造検証コマンドと結果を記録した
- [ ] 利用者指定、プロジェクト規則、実行環境の既定指定から規定ブラウザを決定した
- [ ] `PREVIEW_URL` を規定ブラウザのナビゲーションAPIで開き、接続を確認した。または `not run` と理由を記録した
- [ ] ブラウザ操作検証の実施有無を明記した
- [ ] ユーザー評価未実施なら、検証済みと主張していない
- [ ] 架空の利用データや成功指標を掲載していない
- [ ] 正本ファイル名が `<slug>-wireframe-YYYYMMDD-HHMMSS-mmm.html` で、タイムスタンプを生成・検証完了後に確定した
- [ ] タイムスタンプなしの一時プレビューHTMLを正本として報告していない
- [ ] `WIREFRAME_PROGRESS` マーカーと一時進捗属性が残っていない
- [ ] 進捗表示を使用した場合、`startedAtEpochMs` と `data-progress-elapsed` が残っていない
- [ ] 進捗表示を使用した場合、`EventSource` とプレビュー用URLが残っていない
- [ ] 進捗表示を使用した場合、ホットリロード更新で文書全体のナビゲーションが発生していない
- [ ] 進捗表示を使用した場合、経過時間が `hh:mm:ss` で表示され、更新後も開始時刻を維持した
- [ ] 進捗表示を使用した場合、毎秒の経過時間更新をライブリージョンへ含めていない
- [ ] 進捗表示を使用した場合、進捗表示のための外部依存を追加していない
- [ ] `style[data-pico-css]`が1件だけあり、Pico CSS v2.1.1とMITライセンス全文を含む
- [ ] 最終化後、現在のプレビュータブを正本HTMLのパーセントエンコード済み `file://` URLへ再ナビゲーションした。または `not run` と理由を記録した
- [ ] 静的HTML上でタイトル、`[data-wireframe-root]`、主要フロー、通常ランタイムを確認した。または `not run` と理由を記録した
- [ ] 起動時にプレビューサーバーのPID、process handle、またはjob IDを記録した
- [ ] 静的HTML引継ぎの成功後にだけプレビューサーバーを停止・回収し、停止後も画面が表示されることを確認した
- [ ] サーバー停止後に一時プレビューHTMLと一時作業HTMLを削除し、完了時刻付き正本HTMLだけを残した
- [ ] 停止後にPIDまたはhandleの不在、zombie/defunct状態の不在、プレビューURLの応答停止を確認した
- [ ] 静的HTMLへ引き継げなかった場合、プレビューサーバーを停止せず `intentional-handoff` として残存URLとPIDまたはhandleを報告した
- [ ] 失敗状態のHTMLを正本HTMLとして報告していない
