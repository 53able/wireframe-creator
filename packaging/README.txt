Agent Workspace 0.0.4

「Agent Workspace.app」をApplicationsへコピーして起動してください。
ワイヤーフレームのHTMLは、初期設定では「書類/Agent Workspace」に保存します。

必要環境:
- macOS 14以降
- Python 3.10以降

左下の「モデルプロバイダー」からOpenAI CodexまたはAnthropicを接続します。
ブラウザーで認証し、案件の「モデルを選択」から利用可能なモデルを選びます。
ターミナルでのログインやモデルIDの入力は不要です。
「ログアウト」でそのプロバイダーを使う案件の進行を停止します。
再ログインするまで送信・生成・再試行はできません。
作業内容は保持され、再ログイン後に手動で再試行できます。
モデル実行コンポーネント、Node.js、Marko、Tailwind CSSはアプリに含まれます。
Pythonは既存のインストールを使います。
このビルドはローカル配布用のアドホック署名です。Appleの公証は行っていません。
